# RADAR • Rede de Apoio e Defesa da Aplicação Responsável
> Website institucional moderno, interativo e demonstrativo para gestão e fiscalização de provas educacionais e concursos.

## 🌟 Funcionalidades
- **Landing Page Moderna:** Hero section clean, Bento Grid com pilares de segurança e gestão, calculador interativo para escolas e formulários diretos para WhatsApp.
- **Painel Operacional & Centro de Comando (`operacoes.html`):** Aba técnica com simulação de monitoramento de ambientes, telemetria de salas e protocolos de segurança.
- **Totalmente Responsivo:** Adaptado para celulares, tablets e computadores.
- **Modo Claro / Escuro:** Alternador de tema com persistência.

## 🚀 Como Visualizar
Acesse o GitHub Pages ou abra diretamente o arquivo `index.html`.
